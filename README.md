# Incari Chat (Web Port for Netlify)

A standalone browser port of **Incari Chat** that connects directly to Incari Client's live WebSocket service (`wss://backend.incariclient.org/v1/ws`).

## Deploy to Netlify
1. Extract this `.zip` archive so you have the folder containing `index.html`, `styles.css`, and `app.js`.
2. Go to [app.netlify.com/drop](https://app.netlify.com/drop) and drag-and-drop the extracted folder onto the page.
3. Open your live `.netlify.app` URL and sign in with your Incari account.
